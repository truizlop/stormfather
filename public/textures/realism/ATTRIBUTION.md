# Surface textures

The following textures are by Rob Tuytel, distributed by Poly Haven under CC0.
They are stored locally; the application makes no requests to the Poly Haven API.

- Cobblestone Floor 08: https://polyhaven.com/a/cobblestone_floor_08
- Castle Brick 01: https://polyhaven.com/a/castle_brick_01
- License: https://polyhaven.com/license

Each uses the 1K JPEG diffuse, OpenGL normal, and combined ambient-occlusion / roughness / metalness maps. Local filenames use cobble- and brick- prefixes. No source image edits were made.

Additional natural surfaces (1K color, OpenGL normal and packed AO/roughness/metalness maps):

- `rock-*`: [Rock Boulder Dry](https://polyhaven.com/a/rock_boulder_dry), Poly Haven, CC0.
- `grass-*`: [Aerial Grass Rock](https://polyhaven.com/a/aerial_grass_rock), Rob Tuytel / Poly Haven, CC0.
- `wood-*`: [Weathered Planks](https://polyhaven.com/a/weathered_planks), Poly Haven, CC0.
- `earth-*`: [Brown Mud Leaves 01](https://polyhaven.com/a/brown_mud_leaves_01), Poly Haven, CC0.

Downloaded from the asset URLs returned by https://api.polyhaven.com/files/<asset-id> on 2026-09-07. Files remain local; no runtime external requests are required. License: https://polyhaven.com/license.
