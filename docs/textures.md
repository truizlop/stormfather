# Original generated textures

These project-bound assets were generated with the built-in ImageGen tool and then resized to 1024 pixels and encoded as high-quality JPEG for runtime delivery.

## `public/textures/crem-stone-albedo.jpg`

Prompt summary: a seamless square, top-down, physically plausible storm-polished crem-stone surface with layered blue-black basalt, pale mineral deposits in fractures, small violet lichen, and closed rockbuds. The source is flat-lit and contains no text, landmarks, people, or official artwork.

## `public/textures/shinovar-grass-albedo.jpg`

Prompt summary: a seamless square, top-down, physically plausible sheltered Shinovar surface with rich soil, conventional fine grass, subtle footpaths, clover, mossy pebbles, and faint agricultural furrows. The source contains no text, landmarks, or official artwork.

## `public/textures/highstorm-density.jpg`

Prompt summary: a seamless square grayscale storm-density field with rolling cellular billows, wind shear, fine vapor channels, and a full luminance range for shader opacity and displacement. The source contains no lightning symbols, landscape, text, or official artwork.

The textures are original visual assets for this non-commercial fan project. They are tinted, repeated, and combined with runtime procedural normals and lighting by Three.js.
